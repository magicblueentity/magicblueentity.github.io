Features

Device-Bound Encryption

AES-256-GCM with per-file HKDF subkeys, HMAC-SHA256 integrity, and device binding for strong local protection.

In-Vault Editing

Edit decrypted files directly and automatically re-encrypt each change back into the vault.

Built-in Preview Engine

Preview PDFs, images, videos, and text without ever decrypting the file to disk.

Secure Deletion

Vernichtet files with multiple overwrite methods (Standard, DoD 5220.22-M 3x, Gutmann).

Emergency SOS Scanner

A local scanner to find and permanently destroy orphaned .salt vaults when needed.

Vault Password Management

Flexibly change the password of an existing vault at any time.

Protection & Control

Screenshot/capture protection on Windows, auto-lock, and customizable keyboard shortcuts.

LAN Sharing & VaultBridge

UDP discovery and TCP transfer for sharing plus USB monitoring of removable vault devices.

Modern Theming

Four themes (Standard-dark, Standard-White, High-Contrast, Midnight Blue), custom accent colors, and density settings.

Integrity & Updates

Startup integrity verification and update checks to ensure a clean, trustworthy install.

Changelog

  • New edition codename — EncryptHome is now "Capsule"
  • Reliable in-vault editing — files are re-encrypted atomically and safely on every save
  • Safer secure deletion — atomically rebuilds the vault instead of risky in-place overwriting

  • Hardened decryption length checks to reject malformed vault blobs cleanly
  • Graceful handling of files with no associated application during in-vault editing (no more crash)
  • System integrity check no longer aborts the whole application unexpectedly
  • Enhanced theme engine with Standard-dark, Standard-White, High-Contrast, and Midnight Blue
  • Screenshot/capture protection on Windows

  • Various stability, security, and compatibility improvements
